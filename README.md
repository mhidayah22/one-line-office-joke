One short joke about office life, written for the make.fun bounty
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162):

> I booked a meeting to cut down on meetings, and it ran so long we scheduled a follow-up about the follow-up.

## Run it

```sh
python3 main.py
```

This writes the joke to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`
when it exists, or a local `output/` folder).
